# АвтоПрофи — лендинг автосервиса

Одностраничный адаптивный сайт для автосервиса «АвтоПрофи». Проект написан на чистом HTML, CSS и JavaScript без использования фреймворков и систем сборки.

## ✨ Возможности

- **Адаптивный дизайн** — корректно отображается на смартфонах, планшетах и десктопах.
- **Форма записи** — с валидацией полей и маской для телефона. Отправка через Web3Forms.
- **Интерактивная карта** — на базе Leaflet и OpenStreetMap. Тёмная тема карты.
- **Плавная прокрутка** — навигация по якорям с учётом высоты шапки.
- **Кнопка «Наверх»** — появляется при скролле страницы.
- **Бургер-меню** — удобная навигация на мобильных устройствах.

## 🛠️ Технологии

- **HTML5** — семантическая разметка.
- **CSS3** — Flexbox, Grid, кастомные свойства, медиа-запросы.
- **JavaScript (Vanilla)** — без библиотек и фреймворков.
- **Leaflet** — интерактивные карты.
- **Web3Forms** — обработка формы обратной связи.

## Запуск локально

    git clone https://github.com/TbeerSe/auto-service.git
    cd auto-service
    python -m http.server 8000

Открыть в браузере: http://localhost:8000

## Настройка

В index.html заменить заглушку ключа Web3Forms:

    <input type="hidden" name="access_key" value="YOUR_WEB3FORMS_ACCESS_KEY">

Ключ получить на web3forms.com. Контактные данные (телефон, адрес, email) заменить на реальные.
