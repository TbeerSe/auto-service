# 🔧 АвтоПрофи — сайт автосервиса

Адаптивный лендинг для автосервиса: услуги и цены, форма записи с валидацией, интерактивная карта, тёмная тема с оранжевым акцентом.

## 🔗 Демо

**[Посмотреть на GitHub Pages](https://tbeerse.github.io/auto-service/)**

## ✨ Возможности

- 🌙 Тёмная тема с оранжевыми акцентами
- 📱 Полностью адаптивная вёрстка (mobile-first, от 320px)
- 📝 Форма записи через [Web3Forms](https://web3forms.com) — заявки приходят на email без бэкенда
- ☎️ Маска для российского номера телефона с валидацией
- 🗺 Интерактивная карта проезда (Leaflet + OpenStreetMap)
- 🍔 Бургер-меню на мобильных
- ♿ Доступность: ARIA, фокус-стили, `prefers-reduced-motion`
- 🔝 Кнопка «Наверх» при скролле
- 🎨 CSS-переменные — вся палитра меняется в одном месте

## 🛠 Технологии

- **HTML5** — семантика, SVG-иллюстрации
- **CSS3** — переменные, Grid, Flexbox, media queries
- **Vanilla JavaScript** — без фреймворков
- **Web3Forms** — приём заявок без бэкенда
- **Leaflet 1.9.4** — интерактивная карта
- **Google Fonts** — системные шрифты

## 🚀 Установка и запуск

### Клонировать репозиторий

    git clone https://github.com/TbeerSe/auto-service.git
    cd auto-service

### Запустить локальный сервер

Для работы ES-модулей нужен HTTP-сервер (из-за политики безопасности браузера `file://` не подойдёт).

    python -m http.server 8000

или через Node.js:

    npx serve .

Затем открой http://localhost:8000 в браузере.

## ⚙️ Настройка формы (Web3Forms)

1. Зайти на [web3forms.com](https://web3forms.com).
2. Ввести email, куда должны приходить заявки.
3. Скопировать `Access Key` из письма.
4. Открыть `index.html` и заменить строку:

    <input type="hidden" name="access_key" value="ВАШ_КЛЮЧ">

на свой ключ.

5. Проверить отправку: заполнить форму, нажать «Отправить заявку», проверить почту.

## ⚙️ Настройка карты (Leaflet)

1. Открыть `js/map.js`.
2. Заменить координаты и адрес:

    var LAT = 55.7558;
    var LNG = 37.6173;
    var ADDRESS = 'Москва, ул. Автомобильная, 15';

Координаты найти: Google Maps → правый клик по точке → скопировать первые два числа.
