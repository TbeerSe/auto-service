# AutoService — сайт автосервиса

Адаптивный лендинг для автосервиса: услуги, цены, форма записи, контакты и карта.

🔗 **Демо:** https://tbeerse.github.io/auto-service/

## Возможности

- Адаптивная вёрстка (mobile-first, от 320px до 4K)
- Форма записи на сервис через Web3Forms — заявки приходят на email без бэкенда
- Интерактивная карта проезда на Leaflet + OpenStreetMap
- Секции: hero, услуги, преимущества, цены, отзывы, контакты
- Плавные анимации, доступность (ARIA, focus-стили)
- Тёмная тема с оранжевыми акцентами

## Технологии

- HTML5, CSS3 (Flexbox, Grid, CSS-переменные)
- Vanilla JavaScript (ES-модули)
- Web3Forms — обработка формы без сервера
- Leaflet — карта
- GitHub Pages — хостинг
